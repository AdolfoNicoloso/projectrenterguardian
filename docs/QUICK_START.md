# Project Renter Guardian — Quick start

A short guide to creating properties and running inspections.

---

## 1. Sign in

1. Open the app and create an account or sign in (email/password, phone, or Google where available).
2. First-time users go through onboarding (name, then what you’re here for).

---

## 2. Create a property

You can create a property in two places. Both ask whether you’re **touring** or **already renting**.

### A. During onboarding (first property)

1. Choose **Touring places** or **Already renting**.
2. Enter the address (street, city, state, ZIP). You can skip and add a property later from Home.
3. Optionally add a property listing link.
4. **If touring:** optionally set a personal tour date/time (reminders are based on this; it’s not a landlord booking).
5. Add a nickname and create the property.
6. You’ll be offered to start a **Tour** (touring) or a **Move-in** inspection (already renting). You can skip and do it later.

### B. From Home anytime

1. Tap **Add** in the Home header.
2. Choose **Touring** or **Already renting**.
3. Follow the same address → link → (tour time if touring) → nickname steps.
4. The property appears on Home under **Touring** or **Your rental**.

### Touring → already renting

When you choose a place:

1. Open the touring property.
2. Tap **I chose this place** (or set status to Active via convert).
3. Enter lease start (and term if asked). You can archive other touring properties.

---

## 3. Do a tour or inspection

### What you can start

| Property status | Allowed inspections |
|-----------------|---------------------|
| **Touring** | Tour only |
| **Active** (already renting) | Tour, Move-in, Periodic check, Damage assessment, Move-out |

### Start from Home

1. On a **Touring** card, tap **Start Tour** (or **Continue tour** if you left one unfinished).
2. On an **Active** card, tap **Start inspection** / **Start Move-In inspection**.

### Start from the Inspections tab

1. Open **Inspections** → start a new inspection.
2. Pick the type, then pick an eligible property.
3. Work the guided flow: intro → spaces (add/choose a room, photos + notes) → review → complete.

### During a walkthrough

1. Pick or add a **space** (room).
2. Take photos or pick from your library.
3. Add optional notes when capturing; you can add more timestamped notes later on the photo or space.
4. Mark the space done and continue to the next, or finish when you’re ready.
5. You can leave mid-inspection and resume from Home or the Inspections list.

### After you finish

Completed inspections feed into **Reports** (Insights tab). Open a report to review what was captured.

---

## 4. Handy Home tools

- **Search** — filters properties by nickname or address as you type.
- **Calendar** — header icon opens a month view of scheduled tours.
- **Tour labels** — Scheduled (upcoming), Toured (1+ hour after the time), Not Scheduled.
- **People & invites** — share a property from the property overview so others can view or edit.

---

## 5. Typical paths (cheat sheet)

**Comparing rentals**  
Home → Add → Touring → set tour time → Start Tour → later “I chose this place” → Move-in inspection.

**Already have keys**  
Onboarding or Home → Already renting → create property → Move-in (or other) inspection room by room.

**Mid-tenancy check**  
Open an Active property → Start inspection → Periodic check (or Damage / Move-out as needed).
